# python-fastapi-llm-DB-training

This repository contains code and concepts related to:

- FastAPI
- Large Language Models (LLMs)
- MongoDB
- PostgreSQL
- LangGraph

It also includes a mini-project:

### 🧳 Travel Agency Chat Assistant

A smart assistant built using:

- LangGraph
- OpenAI GPT-4 series models
- TTS-1 for text-to-speech
- DALL·E 3 for image generation

---

## 📁 Contents

- FastAPI API development
- Integration with LLMs
- Database usage with MongoDB and PostgreSQL
- LangGraph-based flow for conversation
- Multi-modal AI features (text, speech, image)
