# Travel Chat Assistant

## Overview

This project is a travel chatbot built using **RAG (Retrieval-Augmented Generation)** and **LangGraph**. It uses the following models:

- **OpenAI GPT-4o-mini** for generating text responses
- **DALL·E 3** for generating images
- **TTS-1** for generating audio

The chatbot provides responses in text, image, and audio formats.

---

## Features

- RAG-based chatbot implementation using LangGraph
- Multi-modal output: Text, Image, and Audio
- Gradio-based UI
- Versioned development (v1 to v3)
- Stores generated outputs (images & audio) in respective folders
